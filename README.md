# Sistema de Gestión - Terminal Portuario (Árbol Rojo-Negro & FIFO)

Este software modular administra el flujo de pasajeros y viajes programados de un terminal portuario utilizando estructuras de datos avanzadas en C de forma eficiente y dinámica.

## Requisitos del Sistema
* Compilador GCC (compatible con el estándar C99 o superior).
* Herramienta GNU Make.
